# Getting system info

## procfs

```
# cpu hardware stats
cat /proc/cpuinfo

# memory hardware stats
cat /proc/meminfo
```

## generic

```
cheat uname
cheat 
```

## hardware info

Hardware listing

```
sudo lswh
lspci [-vv]
```

Pretty printing

```
neofetch
fastfetch
```


## usb

```
lsusb --tree -v
usbview  # windowed
```
